# 1. Project Overview

## Project Name

STAINUS Official Website

---

## Institution

Sekolah Tinggi Agama Islam Nusantara (STAINUS)
Garut, Jawa Barat
Indonesia

---

## Project Type

Official Higher Education Institution Website

---

## Primary Goal

Design and build a fast, modern, professional, responsive, accessible, and scalable official university website using modern web technologies.

The website must represent STAINUS as a trusted Islamic higher education institution while maintaining a contemporary user experience comparable to modern international university websites.

---

# 2. Vision

Create the best modern university website among private Islamic higher education institutions in Indonesia.

The website should communicate:

- credibility
- professionalism
- transparency
- academic excellence
- Islamic values
- technological readiness

without looking outdated or government-like.

---

# 3. Mission

The website should:

- Introduce STAINUS to prospective students.
- Increase student admissions.
- Publish university news.
- Present academic information clearly.
- Become the official digital identity of STAINUS.
- Be easy to maintain and expand.
- Provide an excellent mobile experience.

---

# 4. Project Philosophy

This project follows the principle:

> Simplicity is the ultimate sophistication.

Every page should feel:

- clean
- spacious
- premium
- trustworthy
- elegant
- modern

Avoid unnecessary complexity.

---

# 5. Design Philosophy

The visual language should be inspired by:

- Stanford University
- MIT
- Stripe
- Apple
- Linear
- Vercel

Not by traditional Indonesian government websites.

---

## The UI should prioritize

- whitespace
- typography
- photography
- hierarchy
- consistency
- readability

over decorative elements.

---

## Avoid

- gradient overload
- flashy animations
- unnecessary icons
- information overload
- cluttered layouts
- inconsistent spacing
- multiple accent colors
- skeuomorphic design

---

# 6. Core Values

The website should communicate:

## Academic

Professional and reliable.

---

## Islamic

Elegant and calm.

Do not overuse Islamic ornaments.

Islamic identity should come from:

- colors
- language
- photography
- atmosphere

instead of decorative graphics.

---

## Modern

Technology-oriented.

Responsive.

Fast.

Minimal.

---

## Human

Friendly.

Welcoming.

Accessible.

Easy to navigate.

"I trust this campus."

"I want to study here."

within the first few minutes.

Introduce STAINUS.

---

## Why choose us?

Highlight strengths.

---

## What programs are available?

Display study programs.

---

## What is happening?

Latest news.

---

## How to register?

Admissions call-to-action.

## How to contact us?

Provide complete contact information.

# 12. Content Strategy

Content must be:

- concise
- informative
- authentic
- easy to scan

Avoid long paragraphs.

Prefer:

- headings
- cards
- lists
- statistics
- images

---

# 13. Tone of Voice

Professional.

Friendly.

Confident.

Educational.

Respectful.

Clear.

Never overly promotional.

Avoid excessive marketing language.

---

# 14. Performance Goals

Homepage should feel extremely fast.

Target:

- Lighthouse Performance ≥ 95
- Accessibility ≥ 95
- Best Practices ≥ 95
- SEO ≥ 95

---

# 15. Mobile First

The project must be designed mobile-first.

Every component must work on:

- Mobile
- Tablet
- Laptop
- Desktop
- Large Desktop

Desktop-only layouts are not acceptable.

---

# 16. Accessibility Goals

The website should follow WCAG principles.

Minimum requirements:

- semantic HTML
- keyboard navigation
- sufficient color contrast
- descriptive alt text
- visible focus state
- accessible forms

---

# 17. Future Scalability

The architecture must allow future integration of:

- CMS
- PMB Online
- Academic Information System
- Announcement System
- Event Calendar
- Gallery
- Journal
- Research
- Accreditation
- Downloads
- Multi-language
- Search Engine
- API integrations

without requiring a major rewrite.

---

# 18. Technical Philosophy

Prefer:

- reusable components
- composition over duplication
- server components when possible
- simple folder structure
- maintainable code
- readable code
- scalable architecture

Avoid premature optimization.

---

# 19. Development Principles

Every feature must satisfy:

- Useful
- Reusable
- Responsive
- Accessible
- Performant
- Maintainable

---

# 20. Acceptance Criteria

The project is accepted when:

- Navigation is intuitive.
- Every page follows the design system.
- Components are reusable.
- Mobile experience is excellent.
- Performance is high.
- Codebase is organized.
- SEO fundamentals are implemented.
- Accessibility standards are respected.
- The website represents STAINUS professionally.

---

# 21. Non-Negotiable Rules

The AI must never:

- invent new colors outside the design system
- create inconsistent layouts
- duplicate components
- hardcode repeated content
- ignore responsiveness
- ignore accessibility
- use outdated UI patterns
- create unnecessary pages
- over-design the interface
- sacrifice readability for aesthetics

---

# 22. Definition of Done

The website should feel like a modern international university website adapted for an Indonesian Islamic higher education institution.

The final result must be:

- elegant
- timeless
- maintainable
- scalable
- professional
- trustworthy
- clean
- fast
- accessible

Every design and development decision must support these goals.
